# Descarte Correto de Lixo

## Descrição

O projeto **Descarte Correto de Lixo** é uma aplicação web que ajuda os cidadãos de Campo Grande - MS a localizar o ponto de coleta de lixo mais próximo de sua localização. O objetivo é promover a conscientização sobre o descarte adequado de lixo, proporcionando uma solução prática e acessível para todos os usuários. A aplicação utiliza um mapa interativo para mostrar os pontos de coleta e facilita o descarte de maneira responsável e sustentável.

## Funcionalidades

- **Localização de pontos de coleta**: Permite ao usuário inserir seu endereço e visualizar o ponto de coleta de lixo mais próximo.
- **Mapas interativos**: Utiliza o Leaflet.js para exibir um mapa interativo com os pontos de coleta.
- **Responsividade**: A interface foi desenvolvida de forma responsiva, garantindo uma boa experiência em dispositivos móveis e desktop.
- **Interface intuitiva**: O design foi elaborado para ser simples e fácil de usar, proporcionando uma navegação ágil.

## Tecnologias Utilizadas

- **Frontend**: React.js
- **Mapa interativo**: Leaflet.js
- **Estilização**: HTML5, CSS3 (Flexbox e Grid)
- **Responsividade**: Media queries e design adaptável para diversos dispositivos
- **Versionamento**: Git e GitHub
